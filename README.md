My dream vacation in a single emoji: 🌴 — a palm tree on a quiet tropical beach, warm sun, clear water, and nowhere to be. One palm tree says it all: slow days under the shade, the sound of the sea, and a holiday with nothing on the schedule but rest.

Run `main.py` with `MAKEFUN_OUTPUT_DIR` set; it writes exactly that one emoji to `entry.txt`.
